# Omni-Fleet Fuel Monitoring

This repository is the source-code home for the Omni-Fleet Fuel Monitoring application.

## Planned migration

- Preserve the existing AppDeploy version until the replacement is tested.
- Move the application source to GitHub.
- Replace AppDeploy-specific backend services with Supabase Auth, database tables, and row-level security.
- Deploy the verified application through Vercel.
- Keep each organization's vehicle, driver, workday, fuel, and report data isolated.

## Status

Initial repository setup. The full application source and migration are not yet complete.
